## 🌌 세계관 및 배경 스토리 (Lore)
기원 2194년, 미지의 성계 외곽을 항해하던 우주 개척선 *아이기스 호*가 소행성 벨트의 미확인 중력 이상 현상으로 인해 극저온 소행성 **'Zeta-9'** 지하 암반층으로 불시착했습니다.

외부 기온은 영하 35℃. 대기는 고압의 독성 이산화탄소와 진공뿐입니다.  
살아남은 4명의 수석 대원(과학자, 엔지니어, 광부, 식물학자)은 한정된 비상 산소와 축전지 에너지가 고갈되기 전에 단면 암반을 굴착하고, 전력망과 산소 정화 배관망을 구축하여 소행성 지하 기지를 자급자족 생존 요새로 구축해야 합니다.

## 🎮 주요 시스템 & 게임 플레이 특징

### 1. ⛏ 단면 타일 굴착 & 실시간 대기 시뮬레이션 (Excavation & Gas Dynamics)
- **자유로운 타일 굴착**: 흙, 빙하 얼음, 단단한 현무암, 철광석, 석탄 광맥을 마우스 드래그로 지정하여 굴착.
- **격자형 기체 시뮬레이션 (Cellular Gas Automata)**:
  - **산소 ($O_2$, 하늘색)**: 대원들의 호흡에 필수적인 공기. 위와 수평으로 확산.
  - **이산화탄소 ($CO_2$, 짙은 회색)**: 밀도가 높아 굴착된 기지 바닥층으로 가라앉는 질식 위험 기체.
  - **오염된 공기 ($PO_2$, 연두색)**: 흡입 시 스트레스와 기침, 질병을 유발하는 유독 가스.
  - **진공 (Vacuum)**: 기압이 없는 무산소 구역. 대원들이 숨을 참으며 작업.
- **실시간 대기 모드 (F2)**: 기지 내 기체 분압과 분포를 컬러 히트맵으로 즉시 확인.

### 2. 👥 4인의 거주민 자율 AI & 4대 욕구 시스템 (Colonist Needs & AI)
- **개성 넘치는 4인의 개척민**:
  - **Dr. Alex Vance**: 수석 과학자 (명석한 두뇌, 연구 특화)
  - **Elena Rostova**: 수석 엔지니어 (기계 조작 달인, 설비 운용 특화)
  - **Marcus Briggs**: 베테랑 광부 (무쇠 체력, 고속 굴착 특화)
  - **Dr. Hana Park**: 생태 식물학자 (초록빛 손길, 식량 재배 특화)
- **4대 핵심 생체 게이지**:
  - 💨 **산소(호흡)**: 무산소 구역 진입 시 숨참기 모션(말풍선) 발동, 산소 0% 시 질식 비상사태.
  - 🍞 **칼로리(허기)**: 시간 경과에 따라 감소, 비축된 식량을 찾아 자동 섭취.
  - ⚡ **기력(수면)**: 작업 피로 누적 시 침대로 이동해 수면, 침대 부재 시 바닥에서 기절.
  - 💢 **스트레스**: 저산소, 혹한, 굶주림에 노출 시 스트레스 폭증.
- **2D 단면 물리 & 경로 탐색**: 사다리 오르내리기, 플랫폼 이동, 단차 극복 및 중력 낙하.

### 3. ⚡ 생명 유지 인프라 & 전력망 (Base Infrastructure & Power Grid)
- **발전 시설**:
  - **수동 쳇바퀴 발전기**: 대원이 직접 구동해 즉시 400W 발전.
  - **석탄 화력 발전기**: 석탄을 연료로 지속적인 대용량 600W 전력 공급 (CO2 발생).
- **축전 설비**:
  - **배터리 뱅크**: 잉여 전력을 저장해 비상 시 및 야간에 소비 설비로 방전.
- **산소 & 환경 제어 기계**:
  - **산소 확산기**: 얼음과 전력을 소모해 고순도 산소를 지속 분사.
  - **이산화탄소 스크러버**: 바닥에 고이는 CO2를 화학 촉매로 흡수 여과.
  - **공간 열선 난방기**: 극저온 혹한(-35℃)을 방어하여 기지 내부를 쾌적한 상온으로 보온.
  - **조류 배양기 & 서리밀 재배기**: 지속 가능한 칼로리 식량 생산.

### 4. 🔬 15종 기술 연구 테크트리 (Research Tech Tree)
- 연구대(Research Station)를 건설하고 과학자가 분석 작업을 진행하여 연구 포인트(RP) 축적.
- **4단계 테크트리 해금**:
  1. *고강도 곡괭이, 경량 알루미늄 사다리, 기후 차단형 침대, 베어링 발전기*
  2. *고밀도 축전지 셀, 서리밀 수경재배 농업, 지열 히트파이프, 산소 기류 확산 촉진*
  3. *화력 석탄 발전 설비, 화학 촉매 CO2 스크러버, 영양 농축 가공, 에어로젤 단열 블록*
  4. *기압식 자동 조절 환기구, 스마트 전력 제어기, 생체 활력 제세동실*

### 5. 🚨 돌발 위기 이벤트 (Crises)
- **소행성 극저온 한파 (Cold Snap)**: 기온이 영하 50℃까지 급강하하여 난방 필수.
- **고압 가스포켓 분출 (Gas Leak)**: 굴착 중 매몰되어 있던 대량의 CO2/오염 가스가 기지로 유출.
- **전력망 과부하 정전 (Blackout)**: 순간 스파크로 인한 배터리 방전 위기.

### 6. 🔊 절차적 Web Audio API & 영구 백업
- 외부 음원 에셋 없이 순수 Web Audio API 오실레이터로 곡괭이질 타격음, 해머 건설음, 발전기 회전음, 경보 사이렌, 연구 완료 차임음 실시간 합성.
- **LocalStorage 자동 백업**: 타일 그리드, 대기 밀도, 전선망, 시설, 대원 상태, 연구 내역이 브라우저에 100% 자동 저장/복원.

## ⌨ 조작키 (Controls)

| 조작 | 기능 |
| :--- | :--- |
| **마우스 좌클릭 드래그** | 타일 굴착 지정 / 시설 배치 / UI 조작 |
| **마우스 우클릭 / 휠 드래그** | 카메라 자유 이동 (화면 패닝) |
| **마우스 휠 스크롤** | 카메라 확대 / 축소 (줌 인/아웃) |
| **Space Bar** | 일시 정지 / 재개 |
| **1 / 2 / 3 키** | 1배속 / 2배속 / 3배속 재생 |
| **F1** | 일반 재질 뷰 (Normal View) |
| **F2** | 대기 / 기체 분압 오버레이 (Gas Density Overlay) |
| **F3** | 전력망 / 배선 오버레이 (Power Grid Overlay) |
| **F4** | 온도 / 열역학 오버레이 (Thermal Overlay) |
